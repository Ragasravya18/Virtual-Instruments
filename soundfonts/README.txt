Optional - for the most realistic sound.
Put a General-MIDI SoundFont here and name it  violin.sf2  (or edit SOUNDFONT in config.py).
Any GM SoundFont works because the program number is chosen automatically
(violin / cello / guitar). Free options: GeneralUser GS, FluidR3 GM.
Also install FluidSynth itself and:  pip install pyfluidsynth
If anything is missing the app silently falls back to the built-in synth.
